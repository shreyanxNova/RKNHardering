## 🔍 How to scan your device

The scanning process is automatic and takes a few moments. Follow these steps to find VPN configurations:

1. Click the Start Scan button in the main window.
2. The application begins searching your folders for VPN config files.
3. A progress bar shows you how much of your drive the app has checked.
4. Do not close the window while the bar moves.
5. The scan stops when the progress bar reaches the end.
6. The app displays a list of any detected VPN files in the main view.

## 🛡️ Understanding the results

The app uses colors to show you what it found. 

* Green items mean the system found nothing related to VPN tools.
* Red items mean the scan identified a configuration that might reveal your VPN usage.

If the app finds something, it shows the file path. You can click on the file path to open the folder where the software found the config. You can then review the file or delete it if you no longer need it.

## 🛠️ Frequently asked questions

### Will this software change my system files?
No, the tool reads your files to find information. It does not change or delete your personal data.

### Can I run this tool more than once?
Yes, you can run the scan whenever you want to check your computer for new VPN configurations.

### What should I do if the scan takes a long time?
The scan speed depends on how many files you have on your computer. If you have a large hard drive with many folders, the process might take a few minutes. 

### Does this tool send my data to the internet?
This tool does not send your data to any servers. It works locally on your machine to protect your privacy.

## 📝 Usage tips

Keep your computer clean by running the scan after you uninstall old VPN software. Often, uninstallation tools leave behind old config files. This tool helps you find those leftovers. If you want to keep your network setup hidden, check the list regularly. 

Check for application updates once a month. New versions can find more types of VPN configurations. Always download the update from the official link provided above to ensure you have the safe version of the tool.

## 📁 Troubleshooting common issues

If the application fails to open, check if your antivirus software blocked it. Some security software treats scanning tools with suspicion. You can add an exception for this tool in your antivirus settings if you find it necessary.

If the scan returns an error, restart your computer and try again. A simple restart clears temporary locks on files that might block the scanner from looking into specific folders. 

Ensure you have a user account with full access. If you use a guest account, the program might lack permission to see files in other user folders. Use an Administrator account to get the best results from the scanner.

For further help, refer to the documentation included in the repository. The project team maintains a wiki that contains more details on how the detection logic functions.
